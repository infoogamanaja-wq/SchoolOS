# SchoolOS 5.2.0 — feature map

| Area | Implemented behavior |
|---|---|
| Public website | Responsive botanical green/cream design, clear school onboarding CTAs, useful academic facts, arithmetic challenge with explanations, floating maths/science decoration and reduced-motion support |
| Product previews | Three local screenshots of the actual fictional demo: owner overview, guided setup and parent mobile; interactive selection and explicit demo captions |
| Public pages | Features, how it works, About, Contact, Privacy, Terms, Cookies, Partners and documentation; existing login, school signup and approved school-member registration remain connected |
| Mobile/accessibility | Collapsible keyboard-operable menu, Escape close, visible focus, skip link, semantic headings, touch-sized controls, no horizontal overflow in checked 390px/768px layouts |
| Role documentation | 18 substantive accessible web guides and generated downloadable PDFs, including the full owner setup/operations guide; dashboard links to guides |
| Affiliate enrollment | Dedicated partner signup or application from an existing account; accepted terms, pending review, platform approval/suspension and dedicated dashboard |
| Attribution | Personal random referral links, signed 30-day cookie, first attribution, new-school registration hook, frozen rate/hold, owner identity/email self-referral checks |
| Commission | Integer-kobo calculations from exact server-verified subscription payments, including both current and older checkout paths; one credit per payment/source transaction; trials/free plans do not earn |
| Balance and withdrawals | Separate test/live balances; holds, immediate withdrawal reservations, provider-verified NGN bank recipient, minimum withdrawal, immutable recipient snapshot and personal history |
| Payouts | Explicit Super Admin approval initiates Paystack transfer; reference/amount/currency/recipient verification controls success; timeout reservation, failure/reversal handling, signed callback and scheduled reconciliation |
| Refunds | Provider-verified processed refunds reverse cumulative commission proportionately, event deduplication, recorded negative balance after a paid-out commission |
| Platform controls | Built-in module with explicit additive installation, global on/off, configurable commercial terms, operator identity/contact and independent account suspension |

The guides cover school owner, teacher, parent, student, HR, driver, transport manager, warden/boarding, library, procurement/inventory/assets, communications, school website editor/approver, admissions, finance, affiliate, platform administration, general staff and governance/headquarters/reporting responsibilities.

Existing Finance, Community Hub, WhatsApp configuration, school CMS, role authentication, approved membership, isolated demos, academic, operational and reporting records remain in their existing modules. This release changes the public platform website, not each school's independently managed CMS content.
